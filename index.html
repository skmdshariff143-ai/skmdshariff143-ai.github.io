Credit Card Approval Prediction (CreditGuard AI)

Code Live Demo

An end-to-end Machine Learning pipeline evaluating applicant credit delinquency risk using a Calibrated Random Forest model with cost-sensitive cutoffs and local SHAP explainability.

Problem:

Financial institutions face severe credit default losses from asymmetric misclassification costs, where false negatives (unflagged defaulters) are far costlier than false positives.

Solution:

Trained and benchmarked multiple classifiers (Random Forest, LightGBM, XGBoost, Logistic Regression); selected Calibrated Random Forest as the production champion achieving 97.97% accuracy, 0.7865 ROC-AUC, 0.015387 Brier score (-14.0% error improvement vs uncalibrated), and a cost-sensitive decision cutoff (p* = 0.0395 at 5:1 penalty) delivering 35.77% delinquency recall with local SHAP interpretability.

My Contribution:

Engineered feature pipelines on 438k records, implemented sigmoid probability calibration, optimized 5:1 cost-sensitive decision cutoffs, built Flask 3.0 inference service with Dark/Light dashboard, and integrated de-duplicated local SHAP explanations.

Verified Result: 97.97% Accuracy • 0.7865 ROC-AUC • 0.015387 Brier Score (-14% Error) • 35.77% Default Recall
Python Scikit-Learn Random Forest SHAP Flask 3.0 Docker GitHub Actions
